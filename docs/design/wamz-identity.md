# Wamz Technologies identity

ZamPayroll carries a **Powered by Wamz Technologies** endorsement below its
product name on sign-in, workspace acceptance, team acceptance and the main
workspace. The shared `Brand` component keeps the treatment consistent.

The selected minimal identity uses two precise angled strokes for the W,
navy `#152C36`, copper `#B77950`, and a quiet `TECHNOLOGIES` descriptor. The
artwork is served locally; brand rendering does not depend on an external CDN.

- [Editable Canva logo](https://www.canva.com/design/DAHUu3FR36A/edit)

The Canva design was created by importing the native HTML/vector layout prepared
for this request. The SVG is the scalable application asset. Local copies are
saved under `/home/jamie/Pictures/Wamz Technologies/` as
`wamz-technologies-minimal.svg` and `wamz-technologies-minimal.png`.

An earlier raster exploration is retained locally as `wamz-technologies-logo.png`.
It was generated with the built-in image tool. Prompt: a transparent horizontal
Wamz Technologies lockup, geometric interlocking W ribbons, copper and deep navy,
clean sans-serif WAMZ over TECHNOLOGIES, crisp edges, no mockup or extra slogan.
The later Canva/vector version simplifies that exploration for small UI use.
